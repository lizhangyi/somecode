# 贪吃蛇游戏 PRD

## 1. 产品概述
一个复古风格的贪吃蛇游戏，采用霓虹赛博朋克美学，带有 CRT 显示器的怀旧感。玩家通过方向键或 WASD 控制蛇的移动，吃掉食物增长身体，碰到墙壁或自己的身体则游戏结束。目标是获得尽可能高的分数。

## 2. 核心功能

### 2.1 游戏界面
- **游戏区域**：居中显示的矩形网格，20x20 格子
- **蛇身**：由多个方块组成，带有渐变发光效果
- **食物**：随机生成的闪烁目标点
- **分数显示**：实时显示当前分数和最高分
- **控制提示**：显示操作说明

### 2.2 游戏机制
- 蛇初始长度为 3 节，居中位置
- 食物随机生成，出现在空格子
- 每 150ms 蛇移动一次（可调节）
- 吃到食物：蛇身增长，分数 +10
- 碰撞检测：撞墙或撞自己则游戏结束

### 2.3 游戏状态
- **开始界面**：显示标题和"按空格开始"
- **游戏中**：实时游戏画面
- **游戏结束**：显示最终分数、最高分和重新开始按钮

### 2.4 控制方式
- 方向键：上下左右控制移动
- WASD 键：替代方向键的控制
- 空格键：开始游戏/重新开始
- P 键：暂停/继续

## 3. 核心流程

```
用户打开页面
    ↓
显示开始界面（标题 + 操作提示）
    ↓
按空格开始游戏
    ↓
蛇开始移动 ← 循环
    ↓
检测食物碰撞 → 蛇增长 → 生成新食物
    ↓
检测碰撞（墙/自身） → 游戏结束
    ↓
显示成绩 + 重新开始选项
```

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：霓虹赛博朋克 + CRT 复古显示器
- **主色调**：深紫色背景 (#0a0a1a)
- **强调色**：霓虹绿 (#00ff88)、霓虹粉 (#ff0080)
- **字体**：像素风格字体 (Press Start 2P)
- **效果**：扫描线、发光、闪烁

### 4.2 视觉效果
- 蛇身：霓虹绿渐变，带有发光效果
- 食物：霓虹粉色，缓慢闪烁动画
- 游戏区域：带有 CRT 扫描线效果
- 网格线：微弱紫色线条

### 4.3 响应式设计
- 桌面端：固定尺寸，居中显示
- 移动端：自适应屏幕尺寸，支持触摸滑动控制
