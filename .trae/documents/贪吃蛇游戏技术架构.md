# 贪吃蛇游戏技术架构

## 1. 技术选型
- **纯 HTML/JavaScript**：单文件实现，无需构建工具
- **Canvas API**：绘制游戏画面
- **CSS 动画**：视觉效果增强
- **localStorage**：存储最高分

## 2. 文件结构
```
/workspace/
└── snake-game/
    └── index.html    # 完整的游戏文件（HTML + CSS + JS）
```

## 3. 核心模块设计

### 3.1 游戏状态管理
| 状态 | 说明 |
|------|------|
| IDLE | 初始状态，等待开始 |
| PLAYING | 游戏进行中 |
| PAUSED | 暂停状态 |
| GAME_OVER | 游戏结束 |

### 3.2 数据结构
```javascript
// 蛇：坐标数组
snake = [{x: 10, y: 10}, {x: 9, y: 10}, {x: 8, y: 10}]

// 食物：坐标对象
food = {x: 15, y: 15}

// 方向：枚举
direction = {UP, DOWN, LEFT, RIGHT}

// 游戏配置
config = {
  gridSize: 20,      // 网格大小 20x20
  cellSize: 20,      // 每格像素
  speed: 150         // 移动间隔(ms)
}
```

### 3.3 核心函数
| 函数 | 功能 |
|------|------|
| init() | 初始化游戏 |
| startGame() | 开始游戏 |
| gameLoop() | 游戏主循环 |
| moveSnake() | 移动蛇 |
| checkCollision() | 碰撞检测 |
| eatFood() | 吃食物处理 |
| render() | 渲染画面 |
| handleKeydown() | 键盘事件处理 |

## 4. 渲染方案
- 使用 Canvas 2D API
- 60 FPS 渲染循环
- requestAnimationFrame 优化性能
- CSS 滤镜实现发光效果

## 5. 存储方案
- localStorage 存储最高分
- Key: `snake_high_score`
