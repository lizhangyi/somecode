## wordmaster 工程转换为 Vue 3 + TypeScript + Tailwind CSS

成功将 `D:/work/somecode/projects/wordmaster` 从原生 JS PWA 转换为 Vue 3 + TS + Tailwind 项目。

- 使用 Vite 构建，Vue 3 + TypeScript + Tailwind CSS
- 保留所有原有功能：SM-2 间隔重复算法、IndexedDB 存储、PWA 支持（manifest + sw.js）
