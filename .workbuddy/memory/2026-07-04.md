## 新建子项目：flowchart-canvas

在 `projects/flowchart-canvas/` 下新建了一个基于 Canvas 的流程图库子项目。

### 技术栈
- Vite 6 + TypeScript + Tailwind CSS v4 + 纯Canvas渲染（无框架）
- 参考 snake-game 的项目配置模式

### 实现的功能
1. 四种节点形状：矩形、圆角矩形、菱形、圆形
2. 贝塞尔曲线连线，带箭头，方向感知控制点
3. 节点拖拽、Shift多选、框选
4. 鼠标滚轮缩放（以光标为中心），空格+拖拽/中键平移画布
5. Ctrl+Z 撤销，Ctrl+Y 重做（命令模式，50步上限）
6. 双击节点编辑文字（浮层input）
7. 选中节点显示4个锚点，从锚点拖出连线
8. JSON 导入/导出
9. 属性面板：编辑文字、宽高、颜色
10. Delete键删除选中节点/连线

### 架构要点
- 模块化拆分：types/config/state/canvas/renderer/grid/nodes/edges/anchors/interaction/history/serializer/texteditor
- 渲染管线分层：背景 → 网格 → 连线 → 临时连线 → 节点 → 锚点 → 框选
- 交互状态机：idle/dragging-node/connecting/panning/editing-text/box-selecting
- DPR适配 + 视口坐标转换（screenToCanvas / canvasToScreen）
- 脏标记 + requestAnimationFrame 渲染优化

## 修复连线体验（两个问题）

### 问题1：连线终点角度不对
- **根因**：`bezier.ts` 的 `getControlPoints` 中目标控制点方向算反了
- `p2 = p3 - tv * offset` → 控制点在节点内侧，曲线从内部穿出
- **修复**：改为 `p2 = p3 + tv * offset`，控制点在节点外侧，曲线从外侧顺滑接入

### 问题2：拖拽连线时不显示目标节点锚点
- **根因**：渲染器只画选中节点的锚点，connecting状态下目标节点非选中，锚点不可见
- **修复**：
  1. `types.ts`：TempConnection 新增 `previewTargetId` / `previewTargetAnchor` 预览字段
  2. `anchors.ts`：新增 `drawTargetAnchors()` 函数，绘制目标节点全部4个锚点并高亮预选锚点
  3. `renderer.ts`：connecting状态下额外绘制悬浮目标节点的锚点
  4. `edges.ts`：`drawTempEdge()` 支持吸附到预览锚点，吸附时连线变实色并显示箭头
  5. `interaction.ts`：mousemove 时实时计算最佳锚点（距离最近），mouseup 直接使用预览信息创建连线
