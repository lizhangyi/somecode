## flowchart-canvas Headless 库改造

将 flowchart-canvas 从带 UI 的应用改造为 **Headless 流程图库**。

### 改造内容

**架构变化：**
- 全局单例 state → `FlowchartState` 实例类（所有可变状态为实例字段）
- 模块级 `export let` 变量 → 实例私有字段
- `requestAnimationFrame` 轮询检测选中变化 → `EventEmitter` 事件系统
- 无公共 API → `Flowchart` 主类提供完整 API（addNode/removeNode/addEdge/on/toJSON/fromJSON/destroy 等）
- localStorage 多画布持久化 → 移除（由使用者负责存储，库提供 `dirty` 事件）
- `main.ts` UI 胶水代码 → 移到 `demo/` 目录

**主题方案 C（既支持预设也支持自定义）：**
- `theme: 'dark' | 'light' | ThemeColors`
- `resolveTheme()` 函数：字符串 → 预设颜色对象，对象 → 直接使用

**文件结构重组：**
```
src/
  core/        — 核心层（types, theme, event-emitter, state, flowchart）
  engine/      — 引擎层（canvas, renderer, history, interaction, text-editor, context-menu）
  geometry/    — 几何层（config, geometry, bezier, nodes, edges, anchors, grid）— 全部纯函数化
  demo/        — Demo 应用（main.ts, style.css）
  index.ts     — 公共导出
  style.css    — 库内置组件样式（text-editor + context-menu）
```

**关键设计决策：**
1. 几何层（nodes/edges/anchors/grid）全部改为纯函数，接收 `RenderCtx` 参数（ctx + viewport + theme）
2. 引擎层通过 `import type { Flowchart }` 避免运行时循环依赖
3. 右键菜单和文字编辑器内置但可通过 `options.contextMenu` / `options.textEditor` 关闭
4. 库动态创建 DOM 元素（text-editor textarea、context-menu div），不再依赖 HTML 中的固定元素
5. 事件系统：`on('node:add', cb)` / `emit('selection:change', { selectedIds })` 等
6. 渲染调度：Flowchart 类拥有 RAF 循环，`markDirty()` + `scheduleRender()`

### 正交折线路径优化

优化 `getOrthogonalPath`，解决直线模式下路径混乱问题。

**5 项改进：**
1. 自适应偏移：`off = clamp(dist*0.2, 10, 30)` 替代固定 20px
2. 近对齐直线化：dy/dx < 6px 时跳过弯折直接连线
3. 同方向绕行：right→right / bottom→bottom 时绕到外侧再折回，避免穿节点
4. 共线点简化：`simplifyPath()` 移除重复点和共线中间点
5. 圆角拐弯：`strokeOrthogonalPath()` 用 `arcTo` 替代 `lineTo`，6px 圆角

**新增函数：** `routeBothH`、`routeBothV`、`simplifyPath`、`strokeOrthogonalPath`

### 修复文字编辑后不即时更新

**问题：** 双击节点编辑文字，点击外部后画布不刷新，需再点一次才显示新文字。

**根因：** `TextEditor.finishEdit()` 更新了数据并调了 `markDirty()`，但没调 `forceRender()` 触发重绘。也没 emit `dirty` 事件，导致 localStorage 不保存文字变更。

**修复：**
- `finishEdit()` 末尾添加 `this.fc.notifyDirty()` + `this.fc.forceRender()`
- `Flowchart.notifyDirty()` 从 `private` 改为 public（引擎模块需要调用）

### 添加导出图片功能

新增 `exportImage(options)` API，支持网格/透明两种背景模式。

**新增类型：** `ExportBackground`（'grid' | 'transparent'）、`ExportImageOptions`（background + scale）

**实现：**
- `renderer.ts` 新增 `renderForExport()` — 只绘制连线+节点，不绘制交互元素（选中框/锚点/手柄等）
- `Flowchart.exportImage()` — 创建离屏 canvas，调用 `renderForExport` 渲染后返回 PNG data URL
- Demo 工具栏新增导出图片按钮 + 下拉选择背景（复用 shape-dropdown 样式）
- 导出默认 2x 高清

### 添加 SVG 矢量图导出

新增 `exportSVG(options)` API，采用方案 A（直接从数据模型生成 SVG XML）。

**新增文件：** `src/engine/svg-exporter.ts`
**新增类型：** `ExportSVGOptions`（background + padding）

**实现要点：**
- 复用几何层纯函数计算路径：`getOrthogonalPath`、`getControlPoints`、`getAnchorPosition`、`cubicBezier`
- Canvas → SVG 映射：rect→`<rect>`、circle→`<circle>`、diamond→`<polygon>`、bezier→`<path d="C">`、orthogonal→`<path d="M L">`
- 箭头使用 SVG `<marker>` + `marker-end`，`orient="auto"` 自动旋转
- 文字换行用字符宽度估算替代 `measureText`（CJK≈字号，ASCII≈0.55×字号）
- 正交折线圆角用 `stroke-linejoin="round"` 替代 Canvas 的 `arcTo`
- 网格背景直接生成 `<path>` 线条（细线 0.5px + 粗线 1px）
- viewBox 从所有节点包围盒计算，自动裁剪到内容区域

**Demo 更新：** 文件菜单的"导出图片"子菜单新增 SVG 矢量图分类（网格/透明背景）

### 创建 Vue3 + Element Plus Demo

在 `demo/vue/` 下新建 Vue3 Demo，与 `demo/vanilla/` 平级。

**项目结构：**
```
demo/vue/
  package.json        — vue3 + element-plus + @element-plus/icons-vue + vite + @vitejs/plugin-vue
  vite.config.ts       — Vue 插件 + flowchart-canvas 路径别名
  tsconfig.json        — TypeScript 配置（paths 映射 flowchart-canvas）
  index.html          — 入口 HTML
  src/
    main.ts           — Vue 应用入口（createApp + ElementPlus）
    App.vue           — 主布局（ToolBar + CanvasArea + PropertyPanel）
    components/
      ToolBar.vue     — 工具栏（el-dropdown / el-button / el-icon）
      PropertyPanel.vue— 属性面板（el-form / el-color-picker / el-input-number）
      CanvasArea.vue   — 画布容器（动态创建 canvas 元素）
    composables/
      useFlowchart.ts  — 核心 composable（封装 Flowchart 实例 + 事件监听 + 持久化）
    styles/
      main.css        — 全局样式（CSS 变量 + Element Plus 暗色覆盖）
```

**核心设计：**
- `useFlowchart.ts` — 模块级单例，通过 `ref` 暴露响应式状态（selectedNode / canUndo / zoomScale 等），在 `onMounted` 中创建 Flowchart 实例并监听事件
- 工具栏状态自动同步：`canUndo` / `canRedo` 等存为 `ref`，`history:change` 事件回调中直接赋值，模板自动更新
- 属性面板双向绑定：`v-model` 绑定选中节点属性，`watch(selectedNode)` 防循环更新
- 持久化：监听 `dirty` 事件写入 localStorage，`beforeunload` 兜底

**与 Vanilla Demo 功能对等：**
文件菜单（导出JSON/图片/SVG、导入JSON）、添加节点、撤销/重做、缩放、对齐网格、连线类型、主题切换、属性面板均已实现。
