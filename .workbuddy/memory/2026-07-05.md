# 2026-07-05 工作日志

## flowchart-canvas Headless 库改造

将 flowchart-canvas 从带 UI 的应用改造为 **Headless 流程图库**。

### 改造内容

**架构变化：**
- 全局单例 state → `FlowchartState` 实例类（所有可变状态为实例字段）
- 模块级 `export let` 变量 → 实例私有字段
- `requestAnimationFrame` 轮询检测选中变化 → `EventEmitter` 事件系统
- 无公共 API → `Flowchart` 主类提供完整 API（addNode/removeNode/addEdge/on/toJSON/fromJSON/destroy 等）
- localStorage 多画布持久化 → 移除（由使用者负责存储，库提供 `dirty` 事件）
- `main.ts` UI 胶水代码 → 移到 `demo/` 目录

**主题方案 C（既支持预设也支持自定义）：**
- `theme: 'dark' | 'light' | ThemeColors`
- `resolveTheme()` 函数：字符串 → 预设颜色对象，对象 → 直接使用

**文件结构重组：**
```
src/
  core/        — 核心层（types, theme, event-emitter, state, flowchart）
  engine/      — 引擎层（canvas, renderer, history, interaction, text-editor, context-menu）
  geometry/    — 几何层（config, geometry, bezier, nodes, edges, anchors, grid）— 全部纯函数化
  demo/        — Demo 应用（main.ts, style.css）
  index.ts     — 公共导出
  style.css    — 库内置组件样式（text-editor + context-menu）
```

**关键设计决策：**
1. 几何层（nodes/edges/anchors/grid）全部改为纯函数，接收 `RenderCtx` 参数（ctx + viewport + theme）
2. 引擎层通过 `import type { Flowchart }` 避免运行时循环依赖
3. 右键菜单和文字编辑器内置但可通过 `options.contextMenu` / `options.textEditor` 关闭
4. 库动态创建 DOM 元素（text-editor textarea、context-menu div），不再依赖 HTML 中的固定元素
5. 事件系统：`on('node:add', cb)` / `emit('selection:change', { selectedIds })` 等
6. 渲染调度：Flowchart 类拥有 RAF 循环，`markDirty()` + `scheduleRender()`

### 项目结构重组（同日）

将 Demo 应用从 `src/demo/` 移到顶层 `demo/vanilla/`，库源码独占 `src/`。

**变化：**
- `src/demo/main.ts` → `demo/vanilla/main.ts`（导入路径改为 `../../src/...`）
- `src/demo/style.css` → `demo/vanilla/style.css`
- 根 `index.html` → `demo/vanilla/index.html`（script 改为 `./main.ts`）
- `vite.config.ts` 添加 `root: 'demo/vanilla'`，`server.fs.allow: ['..']`
- `tsconfig.json` include 改为 `["src", "demo"]`
- 删除 `src/demo/` 目录

**目的：** 库与 Demo 分离，后续可在 `demo/` 下添加 `vue/`、`react/` 等框架示例

### Vite 路径别名配置

让 demo 像引用 npm 包一样导入库：`import { Flowchart } from 'flowchart-canvas'`

**配置：**
- `vite.config.ts`：`resolve.alias` 将 `flowchart-canvas` → `src/index.ts`，`flowchart-canvas/style.css` → `src/style.css`
- `tsconfig.json`：`paths` 映射（需 `baseUrl: "."`）
- `package.json`：`exports` 字段（`"."` → `./src/index.ts`，`"./style.css"` → `./src/style.css`）
- `src/index.ts`：补充导出 `NODE_COLORS`、`ZOOM_STEP`、`clamp` 等 demo 需要的常量
- `demo/vanilla/main.ts`：导入路径从 `../../src/core/flowchart` 改为 `flowchart-canvas`
