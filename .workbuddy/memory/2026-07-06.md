## flowchart-canvas 多选节点拖拽修复

### 问题
框选多个图形后，拖拽移动只能移动鼠标按下的单个图形，而不是所有选中图形。

### 修复方案
修改 `src/core/state.ts` 和 `src/engine/interaction.ts`，支持多节点同时拖拽：

1. **state.ts** - 将单节点拖拽状态改为多节点：
   - `dragNodeId: string | null` → `dragNodeIds: string[]`
   - `dragNodeStartPos: Point` → `dragNodeStartPositions: Map<string, Point>`
   - `setDragNode()` → `setDragNodes(ids, startCanvas, startPositions)`

2. **interaction.ts** - 三处逻辑更新：
   - `onMouseDown`：点击已选中节点时，将所有选中节点加入拖拽列表
   - `onMouseMove`：计算位移增量，更新所有拖拽节点位置
   - `onMouseUp`：收集所有节点位置变化，合并为一次撤销操作

## Vue demo 主题切换修复

### 问题
1. 切换浅色主题后，工具栏和属性栏仍为深色
2. 刷新页面后主题丢失，回到深色模式

### 根因
`Flowchart.setTheme()` 的 `theme:change` 事件传出的 `theme` 字段是 `ThemeColors` 颜色对象（含 background、grid、nodeFill 等），不是 `'dark'`/`'light'` 字符串。Vue demo 用它设置 `document.documentElement.dataset.theme`，变成了 `"[object Object]"`，CSS 的 `[data-theme="light"]` 选择器匹配不上。`saveTheme()` 存到 localStorage 的也是 `"[object Object]"`。

### 修复方案
1. **库层面** — `EventMap['theme:change']` 增加 `themeOption: ThemeOption` 字段，`setTheme()` 同时传 `theme`（颜色对象）和 `themeOption`（原始字符串）
2. **Vue demo** — 事件回调改用 `e.themeOption` 同步 CSS 和持久化
3. **CSS** — 添加 `--input-bg` 变量，替代 Element Plus 覆盖样式中硬编码的 `rgba(0,0,0,0.3)`
