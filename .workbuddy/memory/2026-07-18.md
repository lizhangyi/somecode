## 关键事实（ReactLynx，值得复用）
- 入口 `import { root } from "@lynx-js/react"` + `root.render(<App/>)`，不是 `runApp`。
- Lynx 无 `document`/`window` → 禁 `crypto.randomUUID`（ID 自制）；依赖 document/window 的库不可用。
- 事件走 Lynx 原生 `bind*`：点击 `bindtap`、输入 `bindinput` 取 `e.detail.value`（非 React 的 `on*`）。
- 本地存储：Web 用 `localStorage`；Native 需 Native Modules（Android SharedPreferences / iOS NSUserDefaults，要写原生代码）。
- 无浏览器路由，多页面用应用内状态机（useState 维护路由栈；Tab 用 setRoot，编辑页 push/pop）。
- Windows 开发环境对 Lynx 支持差；iOS 出包必须 macOS+Xcode，Windows 编不了。
- 构建脚本用 `rspeedy build`（v0.16 已移除 `--target`，改 environment 体系）。
- 包源可达：`npm view @lynx-js/react` 正常；沙箱批量删 >50 文件会被拒（装 vitest 时触发，已绕到隔离目录）。
