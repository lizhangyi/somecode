# 代码知识库

这是一个用于记录工作中遇到的问题和解决方案的个人代码知识库。

## 快速导航

- **[项目索引](projects/index.md)** - 所有项目列表和说明

## 使用说明

### 工作流程
1. 在公司遇到问题，记录下来
2. 回家后用 AI 辅助编写解决方案
3. 将代码同步到仓库
4. 到公司后查看和使用

### 项目结构

```
├── projects/           # 所有项目
│   ├── json-editor/    # JSON 编辑器
│   └── snake-game/     # 贪吃蛇游戏
├── .trae/              # Trae IDE 配置
└── .idea/              # IDE 配置
```

## 如何添加新项目

1. 在 `projects/` 下创建新文件夹
2. 添加项目代码和 README
3. 更新 `projects/index.md` 中的项目索引

## 技术栈

本仓库涉及多种技术：
- Vue 3 + Element Plus
- 原生 HTML/CSS/JavaScript
- Canvas API
